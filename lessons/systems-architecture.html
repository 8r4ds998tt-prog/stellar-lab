Section 01 // Core Concept

What a CPU actually does

The CPU (Central Processing Unit) is the "brain" of a computer — it fetches instructions from memory, works out what they mean, and carries them out.

Von Neumann architecture

Most computers store both instructions and data together in the same memory, and process them one at a time.

The CPU's main parts

The Control Unit (CU) directs everything, the Arithmetic Logic Unit (ALU) does the maths and logic, and registers hold tiny amounts of data mid-instruction.

General purpose vs embedded

A laptop is general purpose — it runs many different programs. A washing machine's controller is an embedded system — built to do just one job.

Why this matters

Understanding the fetch-decode-execute cycle explains why some computers are faster than others — and it's a core GCSE topic.

Section 03 // Performance Bench

What makes a CPU fast?

Three factors change how many instructions a CPU can get through each second. Adjust them and watch the performance score respond.

Performance score0%
⏱️

Clock speed

Measured in GHz — how many fetch-decode-execute cycles the CPU can attempt per second. Higher = more instructions per second.

🧩

Number of cores

Each core can process instructions independently. More cores means more instructions handled in parallel — but only if the software is written to use them.

⚡

Cache size

A small block of very fast memory built into the CPU. A bigger cache means fewer slow trips to main memory (RAM) for frequently-used data.

🧠

Embedded systems

A washing machine or microwave uses a small, cheap embedded processor built for one repeated job — not raw performance.

🔒 Buses, registers & embedded systems
Address bus: carries the memory address the CPU wants to read or write — it's unidirectional (one way). Its width limits the maximum memory the CPU can address.
Data bus: carries the actual data or instruction being transferred — it's bidirectional. Its width limits how much data can move in one go.
Control bus: carries signals like "read" or "write" that coordinate the transfer, so the CPU and memory agree on what's happening.
Key registers: PC (Program Counter) holds the address of the next instruction. MAR (Memory Address Register) holds the address currently being accessed. MDR (Memory Data Register) holds the data just fetched (or about to be written). ACC (Accumulator) holds the result of the current calculation.

Embedded systems (traffic lights, a car's engine management, a dishwasher) use a processor built into a larger device to perform a small set of dedicated functions — usually cheaper, smaller and more power-efficient than a general purpose CPU, at the cost of flexibility.
