Section 01 // Core Concept

One rule: keep it balanced

Solving an equation means isolating x. Every step must be applied to both sides equally — like a balance scale that must stay level.

Inverse operations

Undo whatever is around x. Addition undone by −, multiplication undone by ÷. Work from the outside in.

Two-step equations

e.g. 3x + 5 = 20 → subtract 5 → 3x = 15 → divide by 3 → x = 5. Undo addition first, then multiplication.

Inequalities

Instead of = use <, >, ≤, ≥. Solve the same way — but flip the sign if you multiply or divide by a negative.

Number line notation

x > 3 → open circle at 3, arrow right. x ≤ 3 → filled circle at 3, arrow left. ● = included, ○ = excluded.

Section 03 // Equation Types

More equation shapes

⚙️

Variables both sides

5x − 3 = 2x + 9 → collect x: subtract 2x → 3x − 3 = 9 → add 3 → 3x = 12 → x = 4.

📦

With brackets

3(x + 2) = 21 → expand: 3x + 6 = 21 → subtract 6 → 3x = 15 → x = 5. Or divide first: x + 2 = 7.

🔢

Unknowns in denominator

12/x = 4 → multiply both sides by x → 12 = 4x → x = 3.

📏

Integer inequalities

Solve 2x − 1 < 9 → 2x < 10 → x < 5. Integer solutions: {..., 2, 3, 4}.

Section 04 // Encrypted: GCSE Stretch

Advanced data

🔒 Forming equations & double inequalities
Forming equations: read the problem, let x = the unknown, write an equation from the words, solve. e.g. "Five more than twice a number is 19" → 2x + 5 = 19 → x = 7.
Double inequality: 3 ≤ 2x + 1 < 11 — subtract 1 from all parts: 2 ≤ 2x < 10 — divide all by 2: 1 ≤ x < 5.
Flip the sign: if you multiply or divide an inequality by a negative number, the inequality sign reverses. −2x > 6 → x < −3.

Simultaneous equations preview: two equations, two unknowns — solve by elimination or substitution. You'll meet this fully in GCSE Year 10.
