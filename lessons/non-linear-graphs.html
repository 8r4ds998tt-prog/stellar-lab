Section 01 // Core Concept

Beyond straight lines

Non-linear graphs have at least one term where the variable is squared, cubed, or in the denominator. Each type has a characteristic shape you need to recognise.

Quadratic: y = ax² + bx + c

Produces a parabola — a symmetric U-shape (or ∩ if a < 0). The coefficient a controls width and direction.

Reciprocal: y = k/x

Produces two curved branches in opposite quadrants — a hyperbola. The graph never crosses either axis.

Cubic: y = x³

An S-shaped curve that goes from bottom-left to top-right (or reversed if negative). One root, one point of inflection.

Key features to find

For quadratics: roots (where y=0), y-intercept (c), and the vertex (turning point — minimum or maximum).

Section 03 // Key Features

Reading a quadratic

🎯

Roots (x-intercepts)

Where the parabola crosses y = 0. A quadratic can have 0, 1 or 2 roots. Use the discriminant (GCSE) to find out which.

⬆️

Vertex (turning point)

The minimum (a > 0) or maximum (a < 0). Its x-coordinate is at x = −b ÷ (2a).

↕️

Y-intercept

Set x = 0 in the equation: y = c. The constant term is the y-intercept — no calculation needed.

🔄

Line of symmetry

The parabola is symmetric about the vertical line x = −b/(2a). The vertex sits on this line.

Section 04 // Encrypted: GCSE Stretch

Advanced data

🔒 Discriminant & completing the square
Discriminant b² − 4ac: if > 0 → two roots; = 0 → one root (tangent to x-axis); < 0 → no real roots (parabola doesn't cross x-axis).
Completing the square: rewrite ax² + bx + c as a(x + p)² + q. This reveals the vertex at (−p, q) directly. e.g. x²+4x+1 = (x+2)²−3, vertex at (−2, −3).
Quadratic formula: x = (−b ± √(b²−4ac)) / 2a. Works for any quadratic — memorise it for GCSE.

Exponential graphs: y = kˣ (k>1 → growth, 0<k<1 → decay). Look for the y-intercept at (0, 1) and a horizontal asymptote at y = 0.
